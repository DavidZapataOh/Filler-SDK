# Filler SDK

> *"Tres archivos y un bond."*

The SDK to deploy vertical UniswapX solvers in `npm install`.

> **Status**: Scaffolding in progress. See [`plans/README.md`](./plans/README.md) for the implementation roadmap.

## What

Today, running a UniswapX solver takes ~4 weeks of infra before the first fill. Filler SDK collapses that to `npm install`.

We don't compete with institutional desks (Wintermute, SCP, Propeller) on majors. We enable the 50+ verticals where they don't reach: hook-specific solvers, treasury internalization, LVR-aware strategies, atomic compound fills.
