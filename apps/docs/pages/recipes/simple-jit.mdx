# Simple JIT

The minimum viable Filler solver — one pool, one currency pair, accept any intent that matches.

## Strategy

```ts
import type { Intent, FillParams } from '@filler-sdk/sdk';

export const strategy = {
  filter(intent: Intent): boolean {
    // Accept any intent for our configured pool
    return intent.input.token === USDC && intent.outputs[0]?.token === WETH;
  },
  decide(_intent: Intent, params: FillParams): boolean {
    // Always submit if we got fillable params from the indexer
    return true;
  },
};
```

## Use case

Single-pool arbitrageurs who want to collect JIT spread without complex inventory management. Filler holds output-token inventory; SDK does the rest.
