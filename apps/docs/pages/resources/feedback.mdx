## Sprint 5.5 highlights — Testnet E2E

- **F-57**: UniswapX has ZERO testnet deployments → mainnet fork promoted to PRIMARY E2E path
- **F-61**: V2DutchOrderReactor's mandatory cosigner trap — `_validateOrder` always calls `abi.decode` on cosignature; empty `0x` panics with empty data BEFORE the typed error fires. Workaround: self-cosign
- **F-62**: anvil's well-known accounts ALL have EIP-7702 SetCode delegation on mainnet → Permit2 takes ERC-1271 path → revert. Workaround: fresh keys
- **F-64**: SDK's `subscribeIntents` only has observational (post-settle) source — no Trading API client until Uniswap publishes the wire format
- **F-65**: v4 mainnet ETH essentially empty (0 swaps in 7 days). Liquidity migrated to Unichain (363 swaps in 1.5h). Public docs imply parity that doesn't exist
- **F-66**: Filler's in-range JIT requires output-token inventory; SDK doesn't pre-flight check it — opaque revert at safeTransfer
