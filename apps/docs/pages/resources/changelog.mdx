## Pre-1.0 (pre-hackathon submission)

Active development. Expect breaking changes per package's CHANGELOG. The release pipeline runs on every PR merge to `main`:

## Convention

Every PR with a `.changeset/*.md` file ships a release. Patch / minor / major scoped per package per the [Changesets convention](https://github.com/changesets/changesets/blob/main/docs/intro-to-using-changesets.md).

## Post-1.0 commitment

Stability commitment: semver strict. Breaking changes only at major bumps. Migration guides for every major. Deprecations announced one minor in advance.
