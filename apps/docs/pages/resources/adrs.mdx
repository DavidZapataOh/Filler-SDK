## What an ADR is

A short markdown doc capturing a single non-obvious decision: **context** + **options considered** + **decision** + **consequences**. We write one whenever a future-team would ask "why does this work this way?" and the answer requires more than two sentences.

## Pattern we follow

- **Numbered**, append-only — `0003-...`, `0004-...`
- **Status**: `Accepted` | `Superseded` | `Deprecated`
- **Title**: imperative + noun (`Choose immutable contracts`, `Adopt JIT inventory hints`)
