## What we ship vs operate

- **We ship**: npm packages, docker images, foundry artifacts
- **We do NOT operate**: any service for customers
- **Customer infra**: solver bot + indexer + dashboard run on customer's RPC + Postgres

## Why self-hosted

- **No central failure point** — the SDK works against any RPC
- **No data leakage** — solvers don't reveal strategy to a third party
- **Composable** — every primitive is replaceable
