# Introduction

Filler SDK is the infrastructure for vertical UniswapX solvers. Three files + a bond and you're operational.

## What this is

A TypeScript SDK + on-chain `Filler.sol` + `FillerBond.sol` + a v4-hook-event indexer (`@filler-sdk/jit-hints`) — the four primitives a UniswapX solver needs, packaged so you can deploy your own in a few hours instead of four weeks.

## What this is NOT

- Not a managed service. Self-hosted, MIT-licensed.
- Not LLM-priced. Solvers are deterministic; LLM (if used) is for audit trail only.
- Not for competing with Wintermute on majors. For the 50+ verticals they don't reach.
