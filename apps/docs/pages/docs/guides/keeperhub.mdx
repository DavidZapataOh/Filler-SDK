# KeeperHub Integration

[KeeperHub](https://keeperhub.com) is the execution + reliability layer for on-chain agents. Filler SDK ships first-class integration for MEV-protected fill broadcasting.

## TL;DR

```ts
const filler = createFillerFromPrivateKey({
  // ...
  keeperHub: {
    baseUrl: process.env.KEEPERHUB_BASE_URL,
    apiKey: process.env.KEEPERHUB_API_KEY,
  },
});

await filler.submitFill(intent, params, { useKeeperHub: true });
```

When `useKeeperHub: true`, the SDK routes the broadcast through KeeperHub — guaranteed inclusion, MEV-protected, with audit trail.

## When to use

- **Production fills** where MEV extraction is a real risk
- **High-value verticals** (treasury rebalances $50K+)
- **Compliance-sensitive flows** that need full audit trail

## When not to

- **Demo / test environments** — adds complexity without benefit
- **Sub-$1K fills** — gas savings of plain RPC outweigh KeeperHub fee
