## Usage

```bash
npx create-filler my-solver
# Interactive prompts: vertical (simple-jit | lvr-aware | treasury-rebalance | custom)
#                     chain (mainnet | unichain | base | arbitrum | optimism | sepolia)
#                     useKeeperHub (yes | no)
```

## Non-interactive

```bash
npx create-filler my-solver \
  --template treasury-rebalance \
  --chain unichain \
  --keeperhub
```

## Templates

- `simple-jit` — single-pool baseline
- `lvr-aware` — redistributes LVR to LPs
- `treasury-rebalance` — DAO internalisation (**hero example**)
- `custom` — minimal scaffold for hook-specific or novel verticals
