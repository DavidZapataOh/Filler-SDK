## Compilation settings

| Setting | Value | Why |
|---|---|---|
| Solidity | `0.8.30` | Latest stable, has transient storage (`bool transient locked`) |
| EVM target | `prague` | Mainnet-deployed Pectra activated |
| Optimizer | `enabled, runs = 1_000_000` | Long-running contracts (immutable, no upgrades) |
| via_ir | `true` | Required for stack-deep callbacks |
| `bytecode_hash` | `none` | Reproducible builds |
