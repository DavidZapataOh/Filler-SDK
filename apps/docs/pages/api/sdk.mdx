## Top-level handle (most common)

```ts
import { createFillerFromPrivateKey } from '@filler-sdk/sdk';

const filler = createFillerFromPrivateKey({
  chainId: 31337,
  privateKey: '0x...',
  rpcUrl: 'http://localhost:8545',
  addresses: { filler, fillerBond, reactor, poolManager },
  indexer: { baseUrl: 'http://localhost:42069' },
});

filler.subscribeIntents(filter, handler);
const params = await filler.prepareFill(intent);
const result = await filler.submitFill(intent, params);
await filler.bond.stake(amount);
await filler.shutdown();
```

Full TSDoc on every public name lives in the source. The hackathon docs site is curated; full TypeDoc auto-generation is a post-hackathon polish (one-line `bunx typedoc` per the [generate-api-docs script](https://github.com/DavidZapataOh/filler-sdk/blob/main/scripts/generate-api-docs.sh)).

## Public surface — by category

### Construction
- `createFiller(opts)` — constructor with explicit viem clients
- `createFillerFromPrivateKey(opts)` — convenience for tests + CI + scripts (used by [`bun run e2e:fork`](https://github.com/DavidZapataOh/filler-sdk/blob/main/packages/sdk/scripts/e2e-fork.ts))
- `createMockFiller(opts)` — no-RPC mock for local development + demo mode (used by [`examples/treasury-rebalance`](https://github.com/DavidZapataOh/filler-sdk/tree/main/examples/treasury-rebalance) `DEMO_MODE=true`)

### Subscribing to intents
- `Filler.subscribeIntents(filter, handler)` — subscribe to intent stream. Today's source is `chainFillIntentSource` (observational); see [F-64](/resources/feedback) for the Trading API gap.
- `IntentFilter` — filter by reactors / chain / strategy

### Filling
- `Filler.prepareFill(intent)` — query indexer + calibrate ticks → `FillParams | null`
- `Filler.submitFill(intent, params, opts)` — broadcast `Filler.execute` with calldata
- `FillParams` — the shape the on-chain Filler expects (matches `contracts/src/libraries/FillParams.sol`)

### Bond
- `BondClient.stake(amount)` / `BondClient.requestUnstake(amount)` / `BondClient.withdraw()` / `BondClient.stakeOf(filler, staker)`
- See [Bond Mechanism](/docs/concepts/bond) for the full lifecycle.

### Errors (typed, narrowable)

```ts
import { FillerError, BroadcastFailedError, IntentExpiredError /* ... */ } from '@filler-sdk/sdk';

try {
  await filler.submitFill(intent, params);
} catch (err) {
  if (err instanceof IntentExpiredError) { /* handle */ }
  else if (err instanceof BroadcastFailedError) { /* handle */ }
  else throw err;
}
```

Full hierarchy: `FillerError` → `BroadcastFailedError` | `IndexerError` | `IntentExpiredError` | `InsufficientLiquidityError` | `RPCError` | `SimulationRevertedError` | `TimeoutError` | `ConfigInvalidError`. Source: [`packages/sdk/src/errors.ts`](https://github.com/DavidZapataOh/filler-sdk/blob/main/packages/sdk/src/errors.ts).
